# 跟踪v2.0
## 效果
1. 解决第二层网络的偶然性误差
2. 解决车辆下半部分被遮挡，仅露出云台部分的跟踪问题

## 大致思路
利用bbox的IOU匹配这一帧的yolo结果和追踪器的预测
    1. 若成功匹配，对于每辆车的(x,y,w,h)进行卡尔曼滤波
    2. 若当前yolo结果未找到在这附近的追踪器，则创建一个新的追踪器
    3. 若追踪器位置未找到yolo结果，则利用前景背景分离，跟踪最近的前景（移动的物体）

## 代码结构和函数说明
1. detector_manager.cpp 184-189行增加追踪器的调用
2. tracker.hpp/cpp
    1. Tracker 对每一辆车的追踪器
    2. TrackerManager 追踪器的管理着，负责创建、删除追踪器以及匹配yolo结果和追踪器
    3. MeanShift 用于利用前背景分离结果进行追踪
