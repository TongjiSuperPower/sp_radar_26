# 通信模块

包含雷达使用的msg定义功能包、sp_referee串口ros2消息互转功能包。
将裁判系统串口通信协议封装，通过话题收发消息即可与裁判系统进行双向通信。

示例
## map_robot_data test
"""
ros2 topic pub /map_robot_data radar_msgs/msg/MapRobotData "
{
    header:{
        stamp:{
            sec: 0,
            nanosec: 0
        },
        frame_id: ''
    },
    hero_position_x: 100,
    hero_position_y: 200,
    engineer_position_x: 400,
    engineer_position_y: 300,
    infantry_3_position_x: 500,
    infantry_3_position_y: 600,
    infantry_4_position_x: 700,
    infantry_4_position_y: 800,
    infantry_5_position_x: 0,
    infantry_5_position_y: 0,
    sentry_position_x: 50,
    sentry_position_y: 50
}
"
"""
